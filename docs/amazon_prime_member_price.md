# Amazonのプライム会員向け価格

価格・在庫チェックと出品判定の共通Amazon取得処理では、
`primeSavingsUpsellAccordionRow` に表示されるプライム会員向け取引価格を優先します。
Chrome・Headless Shellの両方で同じ判定です。

未ログインのプライム欄は会員登録案内だけで、配送・在庫・ギフト情報が省略される場合があります。
通常の新品購入欄と販売者IDが一致し、両方の専用「出荷元」欄でAmazon発送を確認できる場合に限り、
通常購入欄の配送・在庫・ギフト条件を維持し、プライム欄の支払価格を使います。
販売者名だけの一致では適用しません。定期おトク便・中古・単価・参考価格は採用しません。

専用欄がない、非表示、価格が不明、販売者・出荷元を照合できない場合は、従来の通常価格です。
全出品から別の販売者を選んだ場合にも、その出品の価格を維持します。
新品・配送期限・ギフト・数量・ASIN一致等の条件は緩和しません。

プライム欄にポイントが表示されている場合だけ、そのポイントを取得します。
表示がなければ0とし、非セール価格のポイントを流用しません。
会員登録、ログイン、クーポン取得、カート追加、実購入はこの価格取得では行いません。

これはプライム会員である発注アカウントを前提とした仕入価格です。
未ログイン環境で表示された価格のため、実際にそのアカウントで適用されることまで保証するものではありません。
発注時の注文確定前の金額・仕入上限チェックは変更しません。

配布対象は `price_system_listing` の `feature/rakuten-listing` です。
価格・在庫PCは `price_system` の起動コードからこの共通チェッカーを読み込むため、
各PCの `price_system_listing` も更新し、実行中の処理が終わってからワーカーを起動し直してください。
Git配布だけでは既に読み込み済みのプロセスは切り替わりません。
