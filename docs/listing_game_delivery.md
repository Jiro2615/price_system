# ゲーム本体のオンラインコード納品

通常出品・条件無視ASIN出品で共通の必須判定。禁止語の無視、要確認語の承認、同一JANの例外では解除できない。店舗別の設定・移行は不要。既存商品の情報更新だけでは判定しないが、新ASINに入れ替えて販売する場合は対象。

* 選択中のASINのゲームカテゴリ・商品グループ・媒体を確認し、Keepaのダウンロード商品種別（productType = 1）、オンラインコードの版・納品説明などと組み合わせる。別ASINのバリエーションや販促用に加工した説明を商品の形式として使わない。
* コードだけのゲーム本体は「ゲーム本体のオンラインコード納品は出品対象外」。パッケージ・ディスク・ゲームキーカード・カード自体の発送は従来の判定を続ける。特典コード、周辺機器、玩具用カードや追加コンテンツだけをこの理由で禁止しない。
* 配送物かどうか判断できないゲームソフト、または媒体情報と発送方法が食い違うものは「ゲーム本体の納品形態を確認できないため未出品」。不明を商品NGとは断定せず、再判定が必要。物理配送の根拠として標準商品種別と梱包重量の組合せも使うが、オンライン納品を示す情報より優先しない。
* 準備時と楽天送信直前に同じ判定を使い、保存済みの承認・再開も対象にする。追加のKeepaリクエストやブラウザ遷移はない。管理システムと出品PCを更新すること。新規の一括出品は対応していない旧ワーカーでは起動しない。
