## 決定ルール

1. 固定のKeepaカテゴリ対応がAmazonルートと整合する場合は、その楽天ジャンルをそのまま使う。
2. 不整合時は、対応する汎用ジャンルへ自動退避する。
3. Amazonルートが判明するものは、固定対応が不整合でも対応する汎用ジャンルへ自動退避する。ファッション系はAmazonの配下カテゴリからメンズ・レディース・靴・バッグ・キッズ等の汎用先を選び、判別できない場合はレディースファッション>その他を使う。
4. Amazonルート未解決のものは、既存の固定対応または従来の仮ジャンル候補判定を使う。
5. 汎用ジャンルに数値・単位必須属性がある場合は、`-` を入れず属性不足として止める（既に実装済み）。

## 補足

- 現行のカテゴリ対応には、同じAmazonルート内でも複数の楽天大分類が含まれます。これは必ずしも誤りではないため、**既存の整合した固定対応を汎用ジャンルへ置換するものではありません**。
- 汎用ジャンルは、固定対応が未登録または別大分類へ誤対応している場合だけに使用します。
- 全ルートのカテゴリカタログ同期は完了済みです。未解決3件はKeepa側の旧カテゴリIDで、ルートを復元できませんでした。
