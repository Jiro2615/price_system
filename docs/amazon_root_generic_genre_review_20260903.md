## 決定ルールの案

1. 固定のKeepaカテゴリ対応がAmazonルートと整合する場合は、その楽天ジャンルをそのまま使う。
2. 不整合時は、上表で「推奨」または「採用済み」の汎用ジャンルへ退避する。
3. 「要判断」またはAmazonルート未解決は、誤ったジャンルで出品せず `unknown_category` として止める。
4. 汎用ジャンルに数値・単位必須属性がある場合は、`-` を入れず属性不足として止める（既に実装済み）。

## 補足

- 現行のカテゴリ対応には、同じAmazonルート内でも複数の楽天大分類が含まれます。これは必ずしも誤りではないため、**既存の整合した固定対応を汎用ジャンルへ置換するものではありません**。
- 汎用ジャンルは、固定対応が未登録または別大分類へ誤対応している場合だけに使用します。
- 全1,446件の未解決分については、Keepaカテゴリカタログの追加同期後に同じ形式の表へ追記します。
