# 担当PCの価格・在庫チェック表示

Windowsで `price_check_from_db.py --browser shell` を実行すると、小さな進捗ウィンドウを自動表示します。Webから担当PCへ割り当てたShellジョブも対象です。

- 今回のバッチの処理済み件数（エラーを含む）、対象ASIN、最終進捗更新時刻を表示します。
- 最終更新時刻は商品の処理開始・終了時に変わります。通信待ち中も動くアニメーションや正常稼働を保証する表示ではありません。
- ×で閉じても本処理は継続します。同じバッチ中は再表示しません。次のバッチでは再表示します。
- 本処理終了時に自動で閉じます。停止要求の受付状況はこの小窓ではなくWeb側で確認してください。
- Chromeモード、dry-run、Windows以外では表示しません。
- Python標準のTkinterを使用し、追加ブラウザ・外部パッケージ・ネットワークアクセスはありません。表示用に小さなPython子プロセスを1つ使用し、0.5秒ごとに更新通知を確認します。
- Windowsのログイン中デスクトップで実行する必要があります。サービス等の非対話セッションでは見えません。Tkinterが使えない場合もチェック処理は継続します。

## 反映

担当PCの `price_system` リポジトリを停止中に `git pull --ff-only` で更新し、次のジョブを実行してください。価格・在庫チェックのブラウザ設定はShellにします。既存PCでTkinterを含む通常のPythonが導入済みなら、追加インストールは不要です。この変更だけでQNAPの再起動は不要です。

## オフライン検証

`py -3.12 -m unittest discover -s tests -p test_desktop_check_status.py -v`

DBやAmazonには接続しません。
