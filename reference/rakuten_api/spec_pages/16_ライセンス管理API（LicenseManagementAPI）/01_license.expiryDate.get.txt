RMS WEB SERVICE : license.expiryDate.get
Overview
この機能を利用すると、指定した1件のライセンスキーの有効期限を取得することができます。

Endpoint / HTTP Method
Endpoint	HTTP Method
https://api.rms.rakuten.co.jp/es/1.0/license-management/license-key/expiry-date	GET
Request
Request Header
Key	Value
Authorization	ESA Base64(serviceSecret:licenseKey)
Content-Type	application/json; charset=utf-8
Query Parameters
No	Parameter	Descripton	Type	Required	Multiple	Note
1	licenseKey	ライセンスキー	string	〇	1	1件のみ指定可能
Response
Response Header
Key	Value
Content-Type	application/json;charset=utf-8
Response Parameter
Level 1: base
No	Element	Descripton	Type	Mandatory	Note
1	errors	エラー詳細	error	No	
2	expiryDate	有効期限	data string	No	
Level 2: MessageModel
No	Element	Descripton	Type	Mandatory	Note
1	code	エラーコード	string	No	Message Code Reference の一覧はこちら
2	message	エラーメッセージ	string	No
Sample
リクエストが成功した場合
Request
https://api.rms.rakuten.co.jp/es/1.0/license-management/license-key/expiry-date?licenseKey=My1QYevsRH5msnnn
Response (Status: 200 OK)
{
    "expiryDate": "2016-01-01T23:59:59"
}
リクエストが失敗した場合
Request
https://api.rms.rakuten.co.jp/es/1.0/license-management/license-key/expiry-date?licenseKey=My1QYevsRH5msnnn
Response (Status: 400 Bad Request)
{
    "errors": [{
        "code": "DR0006",
        "message": "Bad Request"
    }]
}
