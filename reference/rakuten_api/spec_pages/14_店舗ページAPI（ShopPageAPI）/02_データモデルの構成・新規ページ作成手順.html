ShopPageAPI : データモデルの構成・新規ページ作成手順

店舗トップページのデータモデル構成、新規ページ作成手順はこちらのページでご確認ください。

データモデル構成

Domain概要

データモデルは上図の通り、2つのDomainで構成されています。
Domain名 Domain概要
Page Layout Domain スマートフォン用店舗トップページのレイアウトの取得・更新・公開・削除を行うためのドメインです。
Module Domain ヘッダーエリア、ナビゲーションエリア、共通エリア、パーツ編集可能エリアのモジュールから成るドメインです。
編集可能エリアと編集不可エリアがあります。

モジュール概要

各モジュールの概要は以下の通りです。
エリア 編集可否 概要
ヘッダーエリア × 店舗名、店舗ロゴ、レビュースコア件数、39ショップラベルなどを表示します。
ナビゲーションエリア ○ 店舗の基本情報とよく使われる機能へのナビゲーションを表示します。
このエリアで設定した内容は、楽天市場アプリでのみ表示します。
共通エリア × ショップからの重要なお知らせ、変倍情報などを表示します。
パーツ編集可能エリア ○ 各パーツの内容を設定して、このエリアを自由に構成できます。

ページ作成

新規ページ作成手順

No. 手順 手順詳細
1 ナビゲーションエリアを作成する（POST）
→NavigationIdが生成される		 ShopPage.navigations.insert をご確認ください。
パーツを作成する（POST）
→WidgetIdが生成される		 ShopPage.widgets.insert をご確認ください。
2 レイアウトを作成する（POST）
→手順1で生成された各Idを指定する		 ShopPage.layouts.insert をご確認ください。
