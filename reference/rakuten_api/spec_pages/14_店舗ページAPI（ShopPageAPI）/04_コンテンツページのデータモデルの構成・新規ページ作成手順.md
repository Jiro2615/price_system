データモデル構成


Domain概要
データモデルは上図の通り、2つのDomainで構成されています。

Domain名	Domain概要
Page Layout Domain	コンテンツページのレイアウトの取得・更新・削除を行うためのドメインです。
Module Domain	ヘッダーエリア、パーツ編集可能エリア、フッターエリアのモジュールから成るドメインです。
編集可能エリアと編集不可エリアがあります。
モジュール概要
各モジュールの概要は以下の通りです。

エリア	編集可否	概要
ヘッダーエリア	×	記事サムネイル画像、記事タイトルなどを表示します。
パーツ編集可能エリア	○	各パーツの内容を設定して、このエリアを自由に構成できます。
フッターエリア	×	ショップお気に入り登録、記事のシェア、ショップメニューなどを表示します。
ページ作成
新規ページ作成手順
No.	手順	手順詳細
1	パーツを作成する（POST）
　→WidgetIdが生成される	ShopPage.widgets.insert をご確認ください。
2	レイアウトを作成する（POST）
　→手順1 で生成された各Idを指定する	ShopPage.layouts.common.insert をご確認ください。
Layoutについて
コンテンツページは最大1000ページまで登録可能です。
店舗トップページとは異なり、draft、publicのようなステータスはありません。ページアクセス表示設定によってユーザのアクセス可否が制御されます。
