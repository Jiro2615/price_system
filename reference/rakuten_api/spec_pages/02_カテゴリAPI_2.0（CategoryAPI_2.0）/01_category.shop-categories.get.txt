RMS WEB SERVICE : category.shop-categories.get
Overview
この機能を利用すると、カテゴリIDを指定しカテゴリ情報を取得することができます。

※機能の注意点
・取得できるカテゴリ情報について
カテゴリツリーに紐づいていないカテゴリの情報は取得できません。
カテゴリをカテゴリツリーに紐づけるには、category.category-trees.upsertを利用してください。
