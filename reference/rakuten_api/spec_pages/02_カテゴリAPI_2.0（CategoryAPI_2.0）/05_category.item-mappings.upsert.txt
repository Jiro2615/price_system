RMS WEB SERVICE : category.item-mappings.upsert
Overview
この機能を利用すると、指定した商品管理番号の表示先カテゴリの登録や変更をすることができます。
カテゴリとの紐付けを解除する場合は、category.item-mappings.delete を利用してください。
存在しない商品管理番号を指定したことでエラーにはなりませんが、カテゴリとの紐づけは、最終更新日から24時間以降に削除いたします。
