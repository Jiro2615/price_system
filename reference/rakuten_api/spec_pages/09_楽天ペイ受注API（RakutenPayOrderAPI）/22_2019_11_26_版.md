RMS WEB SERVICE : RakutenPayOrderAPI Response Sample
Overview

この機能を利用すると、これまで、APIリファレンスで公開していた楽天ペイ受注APIのレスポンスサンプルが、テスト用のエンドポイントから取得できるようになります。既定の注文番号を指定してリクエストいただくと、定型のレスポンスサンプルを返却します。

実際の注文ステータスや情報の変更などはできません。

各決済方法・配送方法の注文情報や各機能のレスポンスサンプルをご確認いただくためにご利用ください。
