RMS WEB SERVICE : simulateCouponAmount
Overview
この機能を利用すると、楽天ペイ注文の「送付者情報、注文商品情報と支払方法を更新した場合のクーポン利用額をシミュレーションする」ことができます。
クーポンの再計算については、再計算対象となる期間を設定しております。注文日の翌月末日までが再計算される期間となります。
注文日の翌々月以降に注文内容が変更された場合にはクーポンは再計算されませんのでご注意ください。
実際に注文内容修正を行うタイミングによっては、エラーになるなどシミュレーション結果と異なる場合があります。同期処理となります。

次のステータスの注文にのみ有効です。
・100: 注文確認待ち
・200: 楽天処理中
・300: 発送待ち
・500: 発送済
・600: 支払手続き中
・700: 支払手続き済

SKUプロジェクトにて追加・修正となる項目は背景色を緑に変更しています。
