RMS WEB SERVICE : updateOrderShipping
Overview
この機能を利用すると、楽天ペイ注文の「発送情報の追加・更新」を行うことができます。こちらは同期処理となります。

Endpoint
Endpoint
https://api.rms.rakuten.co.jp/es/2.0/order/updateOrderShipping/

Request Method
