RMS WEB SERVICE : updateOrderOrderer
Overview
この機能を利用すると、楽天ペイ注文の「注文者情報の更新」を行うことができます。こちらは同期処理となります。
注文者情報の対象項目は以下となります。
・注文者 - 名前
・注文者 - フリガナ
・注文者 - 住所
・注文者 - 電話番号
・注文者 - メールアドレス
・注文者 - 性別
・注文者 - 誕生日
