RMS WEB SERVICE : updateOrderDelivery
Overview

この機能を利用すると、楽天ペイ注文の「配送方法の更新」を行うことができます。こちらは同期処理となります。

Endpoint
Endpoint
https://api.rms.rakuten.co.jp/es/2.0/order/updateOrderDelivery/

Request Method

Sample
情報の更新に成功した場合
Request (curl コマンドを使った例)
curl -X POST \
  https://api.rms.rakuten.co.jp/es/2.0/order/updateOrderDelivery/ \
  -H 'Authorization: ESA xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx' \
  -H 'Content-Type: application/json; charset=utf-8' \
  -d '{
    "orderNumber": "123456-20180101-1241583267",
    "deliveryName": "メール便"
}'
Response in JSON format (Status: 200 OK)
{
    "MessageModelList": [
        {
            "messageType": "INFO",
            "messageCode": "ORDER_EXT_API_UPDATE_ORDERDELIVERY_INFO_101",
            "message": "配送方法の更新設定が完了しました。",
            "orderNumber": "123456-20180101-1241583267"
        }
    ]
}
