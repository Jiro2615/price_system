RMS WEB SERVICE : updateOrderMemo
Overview

この機能を利用すると、楽天ペイ注文の「ひとことメモ、担当者情報等の更新」を行うことができます。こちらは同期処理となります。

更新対象は以下となります。

・ひとことメモ
・担当者
・利用サービス名（配送区分）
・メール差込文(お客様へのメッセージ)
・お届け日指定
・お届け時間帯
・サブステータスID

Sample
情報の更新に成功した場合
Request (curl コマンドを使った例)
curl -X POST \
  https://api.rms.rakuten.co.jp/es/2.0/order/updateOrderMemo/ \
  -H 'Authorization: ESA xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx' \
  -H 'Content-Type: application/json; charset=utf-8' \
  -d '{
    "orderNumber": "123456-20180101-1241583267",
    "subStatusId": "3601",
    "deliveryClass": "2",
    "deliveryDate": "2018-01-15",
    "shippingTerm": 724,
    "memo": "ひとことメモです",
    "operator": "楽天担当",
    "mailPlugSentence": "お買い上げ頂きまして誠に有難うございます。"
}'
Response in JSON format (Status: 200 OK)
{
    "MessageModelList": [
        {
            "messageType": "INFO",
            "messageCode": "ORDER_EXT_API_UPDATE_ORDERMEMO_INFO_101",
            "message": "ひとことメモ、担当者情報等の更新設定が完了しました。",
            "orderNumber": "123456-20180101-1241583267"
        }
    ]
}
