RMS WEB SERVICE : updateOrderSubStatus
Overview

この機能を利用すると、複数の楽天ペイ注文の「受注情報のサブステータス」を一括で更新することができます。

こちらは同期処理となります。

Endpoint

https://api.rms.rakuten.co.jp/es/2.0/order/updateOrderSubStatus/
