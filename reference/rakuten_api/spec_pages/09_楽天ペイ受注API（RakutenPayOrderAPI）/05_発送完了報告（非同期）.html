RMS WEB SERVICE : updateOrderShippingAsync

Overview

この機能を利用すると、楽天ペイ注文の「発送情報の追加・更新・削除」を行うことができます。こちらは非同期処理となります。

Endpoint

Endpoint
https://api.rms.rakuten.co.jp/es/2.0/order/updateOrderShippingAsync/

Request

Request Method

Method
POST

Request Header

Key Value
Authorization ESA Base64(serviceSecret:licenseKey)
Content-Type application/json; charset=utf-8

Request Parameter

Level 1: base

No Logical Name Parameter Name Required Type Max Byte Default Description Sample
1 注文番号モデルリスト OrderShippingModelList yes List <OrderShippingModel> - - 指定可能な注文番号モデルの上限は100件まで。
重複する注文番号が指定されている場合、エラーとする。

Level 2: OrderShippingModel

No Logical Name Parameter Name Required Type Max Byte Default Description Sample
1 注文番号 orderNumber yes String 382 - 123456-20180101-00001801
2 送付先モデルリスト BasketidModelList yes List <BasketidModel> - -

Level 3: BasketidModel

No Logical Name Parameter Name Required Type Max Byte Default Description Sample
1 送付先ID basketId yes Number 10 - 2254
2 発送モデルリスト ShippingModelList yes List <ShippingModel> - - 登録可能な発送モデルの上限は20件まで

3 お荷物伝票番号 shippingNumber no String 381 - 以下の入力チェックが適用されます。

・機種依存文字などの不正文字以外
・全角、半角にかかわらず120文字以下

※パラメータなしの場合は値を変更しない
※パラメータあり、かつ、値が未指定の場合は設定されている値の削除 		111222333444
4 発送日 shippingDate no Date 10 - YYYY-MM-DD

※パラメータなしの場合は値を変更しない
※パラメータあり、かつ、値が未指定の場合は設定されている値の削除		 2017-01-02
5 発送情報削除フラグ shippingDeleteFlag no Number 1 0 以下のいずれか

0: 発送情報を削除しない
1: 発送情報を削除する		 0

Response

HTTP Status

Code Status Description
200 OK リクエストが成功した。
400 Bad Request リクエストが不正である。
404 Not Found Request-URI に一致するものを見つけられなかった。
405 Method Not Allowed 許可されていないメソッドを使用しようとした。
500 Internal Server Error サーバ内部にエラーが発生した。
503 Service Unavailable サービスが一時的に過負荷やメンテナンスで使用不可能である。

Response Header

Key Value
Content-Type application/json;charset=utf-8

Response Parameter

Level 1: base

No Logical Name Parameter Name Not Null Type Max Byte Default Description Sample
1 メッセージモデルリスト MessageModelList yes List <MessageModel> - -

Level 2: MessageModel

No Logical Name Parameter Name Not Null Type Max Byte Default Description Sample
1 メッセージ種別 messageType yes String 16 - 以下のいずれか

・INFO
・ERROR
・WARNING		 INFO
2 メッセージコード messageCode yes String 128 - メッセージコードの一覧はこちら MESSAGE_CODE_SAMPLE
3 メッセージ message yes String 1024 - メッセージサンプル
4 リクエストID requestId no String 128 - 正常終了時のみ出力 ede66c43-9b9d-4222-93ed-5f11c96e08e2_20180101120000
5 注文番号 orderNumber no String 382 - 入力チェックエラー発生時のみ出力 123456-20180101-00001801
6 データ番号 dataNumber no Number 10 - 入力チェックエラー発生時のみ出力
指定データ番号。上から１～		 1
7 発送明細ID shippingDetailId no Number 12 - 入力チェックエラー発生時のみ出力
リクエストに設定されている場合、出力する。未設定の場合、Nullを出力。		 45678
