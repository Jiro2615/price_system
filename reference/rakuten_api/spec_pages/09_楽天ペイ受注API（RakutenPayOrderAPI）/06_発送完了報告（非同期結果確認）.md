RMS WEB SERVICE : getResultUpdateOrderShippingAsync
Overview
この機能を利用すると、楽天ペイ注文の「発送完了報告（非同期）」処理の結果を確認することができます。こちらは同期処理となります。

Endpoint

https://api.rms.rakuten.co.jp/es/2.0/order/getResultUpdateOrderShippingAsync/
