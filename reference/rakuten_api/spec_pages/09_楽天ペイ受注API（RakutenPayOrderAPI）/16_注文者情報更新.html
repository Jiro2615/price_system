RMS WEB SERVICE : updateOrderOrderer

Overview

この機能を利用すると、楽天ペイ注文の「注文者情報の更新」を行うことができます。こちらは同期処理となります。
注文者情報の対象項目は以下となります。
・注文者 - 名前
・注文者 - フリガナ
・注文者 - 住所
・注文者 - 電話番号
・注文者 - メールアドレス
・注文者 - 性別
・注文者 - 誕生日

Endpoint

Endpoint
https://api.rms.rakuten.co.jp/es/2.0/order/updateOrderOrderer/

Request

Request Method

Method
POST

Request Header

Key Value
Authorization ESA Base64(serviceSecret:licenseKey)
Content-Type application/json; charset=utf-8

Request Parameter

Level 1: base

No Logical Name Parameter Name Required Type Max Byte Default Description Sample
1 注文番号 orderNumber yes String 382 - 341680-22222222-1241583267
2 変更理由 reductionReason no Number 10 - 以下のいずれか

(お客様都合による)
1: キャンセル
2: 受取後の返品
3: 長期不在による受取拒否
4: 未入金
5: 代引決済の受取拒否
6: その他

(店舗都合による)
8: 欠品
10: その他
13: 発送遅延
14: 顧客・配送対応注意表示
15: 返品（破損・品間違い）

※以下の条件で必須。
1. 減額変更時
2. 楽天市場共通の後払い決済　かつ　発送完了報告後の変更時		 6
3 注文者モデル OrdererModel yes OrdererModel - -

Level 2: OrdererModel

No Logical Name Parameter Name Required Type Max Byte Default Description Sample
1 郵便番号1 zipCode1 yes String 19 - 郵便番号1と郵便番号2両方で20Byte以下の半角英数字とハイフン 158
2 郵便番号2 zipCode2 yes String 19 - 0094
3 都道府県 prefecture yes String 381 - 以下の入力チェックが適用されます

・機種依存文字などの不正文字以外
・全角、半角にかかわらず127文字以下
・海外カゴ注文ではない場合、「47都道府県名」か「国外」		 東京都
4 郡市区 city yes String 381 - 以下の入力チェックが適用されます

・機種依存文字などの不正文字以外
・全角、半角にかかわらず127文字以下		 世田谷区
5 それ以降の住所 subAddress yes String 381 - 以下の入力チェックが適用されます

・機種依存文字などの不正文字以外
・全角、半角にかかわらず127文字以下		 玉川一丁目14番1号
6 姓 familyName yes String 381 - 以下の入力チェックが適用されます

・機種依存文字などの不正文字以外
・全角、半角にかかわらず127文字以下		 楽天
7 名 firstName no String 381 - 以下の入力チェックが適用されます

・機種依存文字などの不正文字以外
・全角、半角にかかわらず127文字以下		 太郎
8 姓カナ familyNameKana no String 381 - 以下の入力チェックが適用されます

・機種依存文字などの不正文字以外
・全角、半角にかかわらず127文字以下		 ラクテン
9 名カナ firstNameKana no String 381 - 以下の入力チェックが適用されます

・機種依存文字などの不正文字以外
・全角、半角にかかわらず127文字以下		 タロウ
10 電話番号1 phoneNumber1 yes String 32 - 以下の入力チェックが適用されます

・半角数字
・電話番号1,2,3の合計が0-32バイト		 03
11 電話番号2 phoneNumber2 yes String 32 - 1111
12 電話番号3 phoneNumber3 yes String 32 - 2222
13 メールアドレス emailAddress no String 83 - 値がない場合は何もしない
・メールアドレス形式
・76 文字		 taro.rakuten@rakuten.com

・男

・年の範囲は「1900年」から「現在年」

Response

HTTP Status

Code Status Description
200 OK リクエストが成功した。
400 Bad Request リクエストが不正である。
404 Not Found Request-URI に一致するものを見つけられなかった。
405 Method Not Allowed 許可されていないメソッドを使用しようとした。
500 Internal Server Error サーバ内部にエラーが発生した。
503 Service Unavailable サービスが一時的に過負荷やメンテナンスで使用不可能である。

    "OrdererModel": {
      "zipCode1" : "158",
      "zipCode2" : "0094",
      "prefecture" : "東京都",

      "familyName" : "楽天",
      "firstName" : "太郎",
      "familyNameKana" : "ラクテン",
      "firstNameKana" : "タロウ",
      "phoneNumber1" : "03",

      "phoneNumber3" : "2222",
