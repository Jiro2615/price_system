RMS WEB SERVICE : updateOrderShippingAsync
Overview
この機能を利用すると、楽天ペイ注文の「発送情報の追加・更新・削除」を行うことができます。こちらは非同期処理となります。

Endpoint

https://api.rms.rakuten.co.jp/es/2.0/order/updateOrderShippingAsync/
