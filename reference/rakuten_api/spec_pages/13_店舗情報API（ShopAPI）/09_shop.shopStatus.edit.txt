RMS WEB SERVICE :shop.shopStatus.edit
Overview
この機能を利用すると、特定機能の移行状況や利用状況を更新することができます。

Endpoint / HTTP Method
Endpoint	HTTP Method
https://api.rms.rakuten.co.jp/es/1.0/shop/shopStatus/{statusKey}	POST
※現在指定可能な「statusKey」はありません。本機能は常に正常終了しますがデータは更新されません。

Request
HTTP Header
No	Key	Value
1	Authorization	ESA Base64(serviceSecret:licenseKey)
2	Content-Type	application/xml; charset=UTF-8
Path Parameters
No	Key	Value
1	statusKey	※現在指定可能な値はありません。
Query Parameters
None

HTTP Body
Level 1: shopStatusBizModel
No	Element	Description	Type	Max Byte	Required	Note
1	updateModel	更新モデル	shopStatus	-	Yes	
Level 2: shopStatus
No	Element	Description	Type	Max Byte	Required	Note
1	statusKey		店舗ステータスのキー	String	255	Yes	※現在指定可能な値はありません。
2	statusValue	店舗ステータスの値	String	255	Yes	以下のいずれか
・MIGRATED：PC用トップページを新店舗トップページに移行する
Request Sample
<?xml version="1.0" encoding="UTF-8"?>
<shopbiz:shopStatusBizModel xmlns:shopbiz="http://rakuten.co.jp/rms/mall/shop/biz/api/model/resource">
    <updateModel>
        <statusKey>pcTopMigration</statusKey>
        <statusValue>MIGRATED</statusValue>
    </updateModel>
</shopbiz:shopStatusBizModel>
