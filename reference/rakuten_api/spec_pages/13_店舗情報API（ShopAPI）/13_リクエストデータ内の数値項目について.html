RMS WEB SERVICE : リクエストデータ内の数値項目について

Overview

ShopAPIは、XML内の数値項目に文字列を入力した際は、以下のように解釈します。


入力値 例 解釈
数値 <field>1</field> 1
全角数値 <field>１</field> 1
半角スペース混合数値 <field> 1 </field> 1
空白文字列 <field></field> 0
半角スペース <field> </field> 0
全角スペース <field>　</field> null
半角テキスト <field>test</field> null
全角テキスト <field>テスト</field> null
半角・全角混合テキスト <field>テスト test</field> null
該当タグなし null
間のスペース <field>1 2 3</field> null
最大値を超える Short：32768
Integer：11212266986		 null
全角スペース混合数値 <field> 1 </field> null
