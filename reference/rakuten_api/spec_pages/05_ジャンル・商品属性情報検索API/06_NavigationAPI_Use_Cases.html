RMS WEB SERVICE : NavigationAPI 2.0 Use Cases


NavigatonAPI 2.0 の機能を利用したUse caseとシーケンスを記載します。

ジャンルに紐づく全ての商品属性情報と推奨値を同時に取得する場合

データ取得フローの例


データ取得の詳細

  1. ジャンル及び商品属性情報が変更された最終日時を取得する。（version.getをリクエスト）
  2. 指定したジャンル情報を取得する。（genres.getをリクエスト）
    　 指定したジャンルのジャンル名称・階層情報・ジャンルパスなどの情報を取得することができます。
    　 必要に応じて、祖先ジャンル・兄弟ジャンル・子ジャンル情報の取得も可能です。
    　 商品登録が可能なジャンルかどうかや、ジャンル統合が行われていた場合、統合先のジャンル情報の取得なども行えます。
  3. 指定したジャンルに紐づく商品属性情報と推奨値を取得する。（genres.attiributes.dictionaryValues.getをリクエスト）
    　 指定したジャンル情報と、商品属性名称・データタイプ・データ制約情報・推奨値の名称などが取得できます。

ジャンルに紐づく商品属性情報を取得した後に、その特定の商品属性に紐づく推奨値を取得する場合

データ取得フローの例

ジャンルに紐づく商品属性情報を取得してlocal DBに保存


特定の商品属性に紐づく推奨値を取得（page/limitパラメータによる制御）


データ取得の詳細

  1. ジャンル及び商品属性情報が変更された最終日時を取得する。（version.getをリクエスト）
  2. 指定したジャンル情報を取得する。（genres.getをリクエスト）
    　 指定したジャンルのジャンル名称・階層情報・ジャンルパスなどの情報を取得することができます。
    　 必要に応じて、祖先ジャンル・兄弟ジャンル・子ジャンル情報の取得も可能です。
    　 商品登録が可能なジャンルかどうかや、ジャンル統合が行われていた場合、統合先のジャンル情報の取得なども行えます。
  3. 指定したジャンルに紐づく商品属性情報を取得する。（genres.attiributes.getをリクエスト）
    　 指定したジャンル情報と、そのジャンルに紐づく商品属性情報（商品属性名称・データタイプ・データ制約情報・単位など）を取得することができます。
  4. 指定したジャンルと商品属性情報に紐づく推奨値を取得する。（genres.attiributes.dictionaryValues.getをリクエスト）
    　 指定したジャンルと商品属性の情報に加え、それに紐づく推奨値の名称を取得することができます。
