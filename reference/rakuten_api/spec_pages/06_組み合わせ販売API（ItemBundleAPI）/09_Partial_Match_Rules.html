RMS WEB SERVICE : Item Bundle Partial Match Rules

Overview

検索時の動作は下記のガイドラインで定義されております。

日本語

組み合わせ管理名称 検索キーワード 詳細 検索結果
日本語で検索するときの注意点および例 検索 漢字で検索 検索可能
けんさく 組み合わせ管理名称にある漢字テキストを平仮名で検索 検索不可
ケンサク 組み合わせ管理名称にある漢字テキストをカタカナで検索 検索不可
とき 平仮名で検索 検索可能
トキ 組み合わせ管理名称にある平仮名テキストをカタカナで検索 検索不可
注 漢字一文字で検索 検索可能

全角文字と半角文字

  • 半角文字の検索キーワードでは、全角文字のテキストを検索できません。
  • 同様に、全角文字の検索キーワードでは、半角文字のテキストを検索できません。

 

組み合わせ管理名称 検索キーワード 詳細 検索結果
ＤＯＵＢＬＥ　ＢＹＴＥ ＤＯＵＢＬＥ　ＢＹＴＥ 組み合わせ管理名称にある全角テキストを全角キーワードで検索 検索可能
DOUBLE 組み合わせ管理名称にある全角テキストを半角キーワードで検索 検索不可

記号

一部の記号で検索する場合は、対象文字をエンコードする必要があります。詳細は下記リストの通りです。

 

記号 エンコード
^ %5E
{ %7B
} %7D
| %7C
\ %5C
# %23
+ %2B
& %26
