RMS WEB SERVICE : Item Bundle Creation Rules

組み合わせの新規登録や更新には下記のルールがあります。

 : 組み合わせを新規登録、更新することができます。バリデーションなどのチェックはありません。

 : 組み合わせを新規登録、更新はできません。バリデーションチェックがあり、エラーが返却されます。

予約商品

子商品として、組み合わせに利用できない商品タイプです。
