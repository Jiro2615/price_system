RMS WEB SERVICE : Item Bundle API Error Codes Reference

    1. Item Bundle Error Codes
    2. Framework Errors

Item Bundle Error Codes
No.	Message Code	Short Message	Underlying Cause
1	B1003	親商品の「mandatory」パラメータは必ず「true」に設定する必要があります。	組み合わせを新規、更新する時に、親商品の選択必須フラッグ「mandatory」は必ず「true」に設定する必要があります。
未指定、あるいは「false」に設定されている場合、該当エラーになります。
2	B1005	親商品は組み合わせ商品リストにも入っている必要があります。	組み合わせ商品リスト「bundleItems」には親商品が含まれている必要があります。
リクエストの「bundleItems」に親商品の商品管理番号が存在しない場合、該当エラーになります。
該当エラーはItemBundle.create と ItemBundle.update 機能において、発生します。
3	B1010	組み合わせられた商品リストのサイズが不正です。リストサイズの範囲は2から4までです。	親商品もリストに入っているため、組み合わせ商品リストのサイズは2から4までです。
リストのサイズは2未満、あるいは4を超えた場合、該当エラーになります。
4	B1011	重複する子商品が存在しています。	重複する商品が存在しています。
組み合わせ商品リストに重複する商品（親商品、あるいは子商品としてすでに存在している）を追加しようとすると、該当エラーになります。
5	B1012	子商品の並び順番号が不正です。	子商品に指定された並び順番号が不正です。
不正な並び順番号に指定し、組み合わせを新規、更新する場合、該当エラーになります。
6	B1014	親商品につき、2つまで表示設定が可能です。	1つの親商品に対して、2つの組み合わせまで表示することが可能です。
組み合わせを新規、更新する時に、1つの親商品に対して、 2つ以上「表示設定」を「表示」に設定しようとすると該当エラーになります。
7	B1015	この組み合わせが既に登録されています。	重複している組み合わせ（同じ親商品と子商品の組み合わせ）が存在しています。
同じ組み合わせを新規、更新しようとすると、該当エラーになります。
8	B1018	組み合わせ管理名称にHTMLタグなどは登録できません。	組み合わせ管理名称にはHTMLタグが利用できません。
組み合わせ管理名称にHTMLタグを入力し、組み合わせを新規、更新しようとすると、該当エラーになります。
9	B1019	組み合わせ販売説明文にHTMLタグなどは登録できません。	組み合わせ販売説明文にはHTMLタグが利用できません。
組み合わせ販売説明文にHTMLタグを入力し、組み合わせを新規、更新しようとすると、該当エラーになります。
10	B1025	更新した組み合わせは存在しません。	指定された「bundleManageNumber」が存在しません。
リクエストパラメーターに不正な「bundleManageNumber」に指定し、組み合わせを更新しようとすると、該当エラーになります。
11	B1026	商品ページ上の表示設定が不正です。
「ACTIVE」 か「INACTIVE」のみ設定可能です。	ItemBundle.create と ItemBundle.update 機能を利用する時に、指定された「表示設定」が不正です。
「ACTIVE」 と「 INACTIVE」以外に設定すると、該当エラーになります。
12	B1029	指定された条件に該当する組み合わせはありませんでした。	指定された条件に該当する組み合わせはありませんでした。
例えば、下記の項目（１つ、あるいは複数）を条件として検索し、結果がない場合は、該当エラーになります。
・親商品管理番号、
・子商品管理番号、
・組み合わせ管理番号、
・表示設定
13	B1030	組み合わせ記録はデータベースの内容と同期していません。	提供された組み合わせ記録の内容はデータベースの内容と異なります。
14	B1032	組み合わせの登録に失敗しました。再度お試しください。	組み合わせの登録に失敗しました。
15	B1034	「type」は「parent」か「child」に設定することが可能です。	パラメーター「type」に設定できるのは「parent」と「child」のみです。
16	B1036	ページサイズの範囲は1から100の間で、かつ、ページ番号は1から100の間で指定してください。	ページサイズの範囲は1から100の間で、かつ、ページ番号は1から100の間で指定する必要があります。
17	B1037	組み合わせの更新に失敗しました。再度お試しください。	システムエラーにより、組み合わせの更新に失敗しました。
18	B1038	組み合わせの削除に失敗しました。再度お試しください。	システムエラーにより、組み合わせの削除に失敗しました。
19	B1050	<parent/child item_manage_no> が店舗に存在しないか、商品の種類が以下のいずれか： -\n\n予約商品\n頒布会商品\nこちらの商品は組み合わせに登録できません。	該当商品が存在しません。
予約商品、頒布会商品は組み合わせに登録できません。
20	B1051	<parent/child item_manage_no> は販売期間指定商品です。販売期間指定商品は組み合わせに登録できません。	組み合わせに利用できない商品タイプです。
21	B1052	<child item_manage_no> は項目選択肢別在庫商品です。項目選択肢別在庫商品は子商品として組み合わせに登録できません。	子商品として、組み合わせに利用できない商品タイプです。
22	B1053	<child item_manage_no> は項目選択肢あり商品です。項目選択肢あり商品は子商品として組み合わせに登録できません。	子商品として、組み合わせに利用できない商品タイプです。
23	B1054	<child item_manage_no> は闇市商品です。闇市商品は子商品として組み合わせに登録できません。	子商品として、組み合わせに利用できない商品タイプです。
24	B1055	<parent/child item_manage_no> は医薬品・酒類・コンタクトレンズジャンルの商品です。 医薬品・酒類・コンタクトレンズジャンルの商品は組み合わせに登録できません。	医薬品・酒類・コンタクトレンズジャンルの商品は組み合わせに登録することが禁止されています。
25	B1056	組み合わせ管理番号に不正な文字が入力されています。	組み合わせ管理番号には小文字のアルファベットと数字のみが利用できます。
26	B1058	システムエラーが発生しました。再度お試しください。	情報取得中、システムエラーが発生しました。
27	B1059	正常に処理が終了しましたが、システム遅延のため反映されていません。	ItemBundle.create、 ItemBundle.update、 ItemBundle.delete などの操作は正常に処理が終了しましたが、システム遅延のためすべて反映されていません。しばらくお待ちください。
28	B1060	指定された組み合わせ管理番号 <bundleManageNo> がすでに存在しています。	指定された組み合わせ管理番号がすでに存在している場合、該当エラーになります。
29	B1061	組み合わせされた親商品は変更できません。	Itembundle.update機能を利用し、親商品を変更しようとすると、該当エラーになります。
30	B1062	キーワードが長すぎます。「組み合わせ管理名称」は32文字以下で指定してください。	検索時に指定した「組み合わせ管理名称」が、32文字より長い場合、該当のエラーになります。
31	B1063	漢字以外を利用した「組み合わせ管理名称」の検索には、2文字以上を指定してください。	検索時に指定した「組み合わせ管理名称」が2文字に満たない場合、該当のエラーになります。
ただし、漢字での検索の場合、1文字のみの指定が可能です。
32	B1064	キーワードが長すぎます。「組み合わせ管理番号」は32文字以下で指定してください。	検索時に指定した「組み合わせ管理番号」が、32文字より長い場合、該当のエラーになります。
33	B1065	「組み合わせ管理番号」には2文字以上を指定してください。	検索時に指定した「組み合わせ管理番号」が2文字に満たない場合、該当のエラーになります。
34	B1066	「組み合わせ管理番号」に、許可されていない文字が含まれています。「組み合わせ管理番号」での検索には半角英数字、_、-のみが利用できます。	「組み合わせ管理番号」に半角英数字、_、-以外が含まれていた場合に、該当のエラーになります。
35	X0000	「type」と「itemManageNumber」にNULLは登録できません。	アイテムタイプ「type」と商品管理番号「itemManageNumber」はどちらもNULLでは登録できません。
36	B1067	<parent/child item_manage_no> は在庫情報、配送情報が登録されていないため、商品編集ページから登録してください。	在庫情報、配送情報が登録されていない商品を含む組み合わせ販売を登録、更新した場合、該当エラーになります。
37	B1068	<parent/child item_manage_no> は1度削除されている商品のため、組み合わせの更新ではなく新規登録してください。	再利用された商品管理番号を持つ組み合わせ販売を更新した場合、該当エラーになります。
Framework Errors
No.	Message Code	Short Message	Underlying Cause
1	GE0001	Invalid value on field <field_name>.	リクエストボディのフィールドに下記にエラーがある場合、該当エラーになります。
・データタイプ不一致（数値フィールドに文字列を指定）
2	GE0002	Invalid value on parameter <parameter_name>.	クエリパラメーターや、URLパラメーターに下記のエラーがある場合、該当エラーになります。
・データタイプ不一致（数値フィールドに文字列を指定）
3	GE0003	Invalid value on header <header_name>.	ヘッダに下記のエラーがある場合、該当エラーになります。
・データタイプ不一致（数値フィールドに文字列を指定）
4	GE0004	Missing required field <missing_field_name>.	リクエストボディにある特定のフィールドが未設定の場合、該当エラーになります。
5	GE0005	Missing required parameter <missing_parameter_name>.	リクエストボディにある特定のクエリパラメーター、あるいはURL パラメーターが未設定の場合、該当エラーになります。
6	GE0006	Missing required header <missing_header_name>.	リクエストボディにある特定のヘッダが未設定の場合、該当エラーになります。
7	GE0007	Requested path does not exist.	リクエストにあるURLが間違えた場合、該当エラーになります。
8	GE0008	The call is unauthorized. Check Authorization header.	Authorizationが失敗した場合、該当エラーになります。
9	GE0009	The HTTP method utilized is not supported by this resource.	許可されていないメソッドを使用しようとしました。
例：POSTメソッドを利用すべきフォームでGETメソッドを使う。
10	GE0010	Request body must not be empty.	POST あるいは PUTのリクエストボディが空の場合、該当エラーになります。
11	GE0011	Request body cannot be processed.	リクエストボディに誤りがあり、処理できない場合、該当エラーになります。
12	GE0012	Media Type <media_type> is not supported.	Accept関連のヘッダに受理できない内容が含まれている場合に返されます。
例：'Accept-type'はXML、リスポンスはJSON。
13	GE0013	Forbidden to update this field.	該当リソースの更新権限を持っていないユーザが更新リクエストしようとすると、該当エラーになります。
14	GE0014	The resource with id: <given_id> does not exist.	バックエンドに該当リクエストリソースは存在しない場合、該当エラーになります。
