RMS WEB SERVICE : 購入履歴変更通知
「システム情報通知」の購入履歴変更通知サービスで提供されれる、格納データについて定義します。
インターフェース項目は、「システム情報通知」の内容に準じます。

ユーザが購入履歴変更機能で、何も変更せずに更新ボタンだけを押した場合、システムイベント通知サービスからの通知は行われませんのでご了承ください。

実装の前に、「RMS WEB SERVICE : システムイベント通知サービス/４．制約事項」をご確認ください。
