備考


審査結果通知の種別については以下の通りです。
・審査結果コード「1：発送指示」の場合
　　ユーザが注文してから14日以内に店舗様にて注文確認され、審査OKだった。

・審査結果コード「2：楽天側キャンセル」の場合
　　ユーザが注文し、注文確認した後、カード決済の審査がNGだった。
　　ユーザが注文し、注文確認した後、銀行振込の審査がNGだった。
　　ユーザが注文してから、注文確認されないまま15日経過した。
　　ユーザが注文し、14日以内に注文確認したが、その翌日以降にユーザが受注をキャンセルした。（カード決済以外）　
　　警告表示注文（RMS注文一覧・詳細表示でグレーの注文）を注文確認し、翌日になった。

・審査結果コード「3：発送指示取消※2」の場合
　　オーソリ取得日から30日以上店舗様から「発送完了報告」がされない場合に、店舗様にご登録いただいた発送日の7日前に楽天にて再度オーソリを取り直した結果、オーソリNGとなった。
　　店舗様でのキャンセル処理があった。
