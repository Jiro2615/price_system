RMS WEB SERVICE : 再入荷リクエスト通知（SKU移行前）

 

「システム情報通知」の再入荷リクエスト通知サービスで提供される、格納データについて定義します。
インターフェース項目は、「システム情報通知」の内容に準じます。


実装の前に、「RMS WEB SERVICE : システムイベント通知サービス/４．制約事項」をご確認ください。

 

こちらのページはSKU移行前受注（SKU移行前リクエスト）用の再入荷リクエスト通知となります。

SKU移行後受注（SKU移行後リクエスト）に対する通知については「再入荷リクエスト通知（SKU移行後）」をご確認ください。

※4100：再入荷リクエスト通知（SKU移行前）はSKU移行後は通知されなくなります。SKU移行後も継続して再入荷リクエスト通知を利用希望の場合は、4200：再入荷リクエスト通知（SKU移行後）のお申込みが必要です。
